# ♟️ The Maruf Opening

A sharp, off-beat, engine-tested chess opening system built for online blitz.


## Core Philosophy
1. **Center Bait (`3. Bb2`):** Leave `d4` undefended to lure Black into opening the `a1–h8` diagonal for the sniper bishop.
2. **Structural Trade (`5. Bxf6`):** Intentionally trade the dark-squared bishop for Black's knight to permanently double and weaken their kingside pawns.
3. **Tactical Strike (`8. Nd5!`):** Leap into the center with a lethal `Nc7+` royal fork threat.
